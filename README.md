# Addis Eats

Addis Eats is a Next.js scaffold for an online food marketplace. Authentication,
role-based access control, restaurant and dish search, status polling, and the
performance optimization work are planned but are not implemented yet.

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Environment variables

No environment variables are required by the current scaffold. Keep local
credentials in `.env.local`; environment files are excluded by `.gitignore`.
